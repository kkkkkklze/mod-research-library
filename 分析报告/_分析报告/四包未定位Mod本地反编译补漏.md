# 四包"未定位 mod"本地反编译补漏报告

> 背景：此前四个整合包共 223 个 mod 既找不到公开仓库、也没有源码。用户提供了 PCL2 的 `versions` 目录（23 个已安装整合包），本轮从中取出对应 jar 做了**反编译补漏**。

## 结果

| 整合包 | 未定位 | 本轮补上反编译 | 仍缺 |
|---|---|---|---|
| 璇穹之歌 1.21.1 | 88 | **85** | 3 |
| FIDR 暗涌 1.20.1 | 29 | **29（全覆盖）** | 0 |
| 星轨重铸 1.21.1 | 23 | 10（该包**未安装**，跨包蹭到 10 个） | 13 |
| ATM10 1.21.1 | 83 | **81** | 2 |
| **合计** | 223 | **205** | 18 |

外加：**13 个此前克隆失败的仓库**（多数是我猜错仓库名）也从本地 jar 元数据里找到了正确地址，其中 44 个新仓库已并入各包对照表。

## 规模

- 有效补漏 mod：**214 个**（剔除 3 个宽松匹配误配）
- 反编译总代码量：**2,780,385 行**（CFR）
- 新发现仓库：**44 个**（来源都是 jar 内 `mods.toml` 元数据，最可靠）
- 产物：`源码库/_参考仓库/_pack_decompiled/<整合包>/<jar名>/`，速览卡片在 `_pack_decompiled/_卡片/`

## 仍有缺口的 18 个

- 璇穹之歌 3 个：`CBC AT`（机械动力火炮：先进技术）、`橱柜库.jar`、`ruok`（渲染优化）——本地 jar 名与元数据都对不上
- 星轨重铸 13 个：**该整合包没有安装**，只能靠跨包蹭到 10 个；剩下 13 个（如 create 附属、sable 系列）需要安装该包或提供 jar
- ATM10 2 个：`ATO - All the Ores`、`Clean Swing Through Grass`（另有 1 个 BSL Shaders 是光影包不是 mod）

## 方法备注

1. 用 PCL2 `versions\<包>\mods` 下的 jar 建索引（1230 个 jar，含 `mods.toml` 元数据）
2. 与四包"未定位"名单做三轮匹配：精确键 → 词切分+双向包含 → 跨包匹配（星轨）
3. 对命中者用 CFR 反编译 + 生成速览卡片；同时从 jar 元数据里回收仓库地址
4. 反向价值：本地安装的版本比整合包 JSON 更新（如璇穹之歌本地 421 个 jar vs JSON 386 个 mod），因此这批反编译也覆盖了"JSON 里没有但本地有"的新版本 mod
